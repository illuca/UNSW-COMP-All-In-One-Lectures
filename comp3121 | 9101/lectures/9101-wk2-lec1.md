## activity selection

There is a list A.

This list has n activities.

For each activity, it has starting time and finishing time.

And two activities cannot take place at the same time.



Your job is to find a subset of the list and the subset contains as many activities as possible.



Solution: greedy

If we has selected an activity, the best choice for next activity is the one with earliest end time and not conflicting with the current one.



To prove the correctness, we need to list all solutions  and prove all these solutions can be gained by greedy algorithm.



![image-20230608130403644](/Users/luca/Library/Application Support/typora-user-images/image-20230608130403644.png)



The teacher knows the correct solution which is that any subset with 4 activities.

In image, the first line has 4 blue activities which is our subset.

This subset is not using greedy and we can use greedy to modify it and after modification, the num of activities will also be 4.



Thus for any alternative solution, we can convert it into a greedy solution, thus proving the correctness of greedy solution.



 **time complexity of greedy**

We always choose the next activity with earliest end time. So we should sort the activity list in increasing order of its element's end time.

And sort costs O(nlogn) time.



But how do we check if the current chosen activity conflict with the previous one. 

We check if starting time of current chosen is after the finishing time of the previous, then current activity is valid. 



Thus we need to keep track of the latest finishing time.

Since finishing time all processed activities are in increasing order. The latest finishing time is just the last activity that has been chosen.



If the current chosen activity is valid, then update the latest finishing time in O(1) time.



Thus, the T(n)=O(nlogn), dominated by sorting.
