
# an old puzzle: find the couterfeit coin
There are 27 coins that have the same denomination.
We know there is a fake one and it is ligher than others.

Find the fake coin by weighing coins on a pan balance only three times.

hint:
you can reduce the search space by a third in each weighing.

The solution is:
Divide the coins into three groups of nine, A,B and C.
Weigh group A against B.
	If one group is lighter than another, it contains the counterfeit coin.
	If instead both groups have equal weight, then C contains the target.

Repeat with three groups of three, then three groups of one.


The method is called divide and conquer.

# counting inversions in an array
Now you have m users and the m users rank n movies.

For any user A and B in m users, you want to know how similar their taste are.

Then how should we mesure the degree of similarity?

We can enumerate the movies on the list of user B.
Set top choice chosen by B as index 1.
Set second choice as index 2 and so on.

For the ith movie on the B'list, B[i], we check B[i] on A's list and find A[a(i)]=B[i].

The num of inversions can reflect how different their tastes are.
We counter the num of pairs of movies i,j and i < j but a(i)>a(j).
i < j means B[i] is better than B[j] on B's list.
A[a(i)]=B[i] and A[a(j)]=B[j] and a(i)>a(j)

# deterministic linear time algorithm for order statistic

There is a set S. It has n numbers.

If n is odd,  the num of elements greater than median will equal that less than median.

If S is sorted, then the median number will be in the middle of S.

Order statistic is:

There is a set S and it has n numbers.

Find kth max element in S.

Obviously, we can use sort and solve it in O(nlogn).

But actually, this pbl can be solved in O(n).

In 1973, Manuel Blum, Robert W. Floyd, Vaughan Pratt, Ron Rivest, and Robert Tarjan made an algorithm together.



## Algorithm Select

Firstly, split the numbers in S into groups of five.

Thus every group has 5 elements.

There are totally ceil(n/5) groups.

We sort these groups and then select all of their median.

So all of the medians form a new array S'.

Then we sort S' and get its median and mark the median as pivot.



There are at least floor(total groups/2) medians smaller than pivot and at least that many larger than pivot.

floor(total groups/2)=$\lfloor n/10 \rfloor$

Thus there are at least 3 * $\lfloor n/10 \rfloor$ numbers that less than pivot. And the remaining is only 7 * $\lfloor n/10 \rfloor$.



So we have T(n)$\leq$ T($\frac{n}{5}$)+T($\frac{7n}{10})$+Cn



And then we want to prove that T(n) is linear time, thus proving it is a efficient algorithm to find kth element.



We already know T(n)<11Cn.

Then we use induction to prove it.
